# TDAH Kids - Proyecto Modular 🧠✨

Plataforma educativa e interactiva diseñada para niños con TDAH, padres y maestros. El objetivo de este sitio es concientizar sobre el TDAH, eliminar estigmas y proporcionar herramientas didácticas en un entorno visualmente tranquilo y profesional.

## 🚀 Características principales
*   **Diseño Minimalista "Pure White":** Inspirado en la estética de Apple para reducir la sobreestimulación visual.
*   **Scroll-Driven Animations:** Experiencia de navegación cinemática y fluida.
*   **Módulos de Aprendizaje:** Información clara y empática sobre el TDAH con seguimiento de progreso local.
*   **Sección de Juegos:** (En desarrollo) Actividades diseñadas para entrenar el enfoque y la memoria.
*   **Privacidad Total:** Los datos de progreso se guardan localmente en el navegador (`localStorage`).

## 🛠️ Tecnologías utilizadas
*   [React](https://reactjs.org/) (JavaScript)
*   [Vite](https://vitejs.dev/) (Build tool)
*   [Tailwind CSS v4](https://tailwindcss.com/) (Framework de estilos)
*   [React Router](https://reactrouter.com/) (Navegación)

## 📦 Instalación y Desarrollo
1. Clona el repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

## 🌟 Misión
Convertir el diagnóstico de TDAH en una oportunidad para descubrir talentos únicos, proporcionando un espacio donde la neurodiversidad es el motor del aprendizaje.
